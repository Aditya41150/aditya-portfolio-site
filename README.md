# Aditya — developer portfolio

Personal site for [Aditya](https://github.com/Aditya41150): full-stack and Flutter work, systems projects, and a short case-note layout.

This repo is an export of the redesign. Edits made later in the Grok app builder are **not** synced here automatically — push again when you want GitHub to match.

## Stack

- React 19
- TanStack Start / Router
- Tailwind CSS v4
- Vite

## Run locally

```bash
npm install
npm run dev
```

The preview in Grok serves on port 8080. A production build:

```bash
npm run build
```

## Content

Project copy, links, and skills live in [`src/lib/portfolio.ts`](src/lib/portfolio.ts). Resume PDF is `public/resume.pdf`.
